Featured Silicon Architecture Project

Phase-Aware Adaptive LLC Replacement (PA-RRIP)

Cycle-Accurate ChampSim Engine & Synthesizable SystemVerilog RTL

Course: BEVD207L Computer Architecture | S M Kousika & Kavya Raja G
SystemVerilog RTL ChampSim C++ Cadence Genus @ 2.0 GHz SPEC CPU2017 Icarus Verilog

Modern memory workloads shift between streaming vector scans, tight temporal loops, and thrashing pointer-chasing. PA-RRIP dynamically samples 5 microarchitectural runtime signatures across 10,000-cycle epochs to steer cache insertions into Mode 0 (SRRIP), Mode 1 (LRU), or Mode 2 (BRRIP) with zero per-line storage overhead, stabilized by a 2-bit saturating hysteresis filter.

1. Phase Monitor (RTL)
Tracks accesses, misses, spatial locality, and consecutive address stride delta (Δ == Δprev) across fixed-interval epoch windows.
2. Rule Classifier (RTL)
Pure shift-and-add decision tree logic with zero division overhead, paired with a 2-bit saturating hysteresis register to prevent policy flapping.
3. Unified LLC Engine (RTL)
16-way associative set replacement controller dynamically steering 2-bit RRPVs without dedicated duel-set pollution or cache flushes.
